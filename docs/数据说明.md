## 预算估算（重要）

按输入 token 估算（英文约 4 字符/token）：

| 场景 | token 总量 | 按 ¥1/百万 估 |
|---|---|---|
| oracle · 50 题 | 0.3 M | **≈ ¥0.3** |
| oracle · 500 题 | 3.3 M | **≈ ¥3** |
| S · 50 题 | 6.1 M | **≈ ¥6** |
| **S · 500 题（全量）** | **61.2 M** | **≈ ¥60–120**（按实际单价） |

**结论**：**oracle 上做冒烟测试几乎不花钱**，可以放心多跑；S 全量要几百元级别，**务必先跑 50 题验证流程再放开**。
