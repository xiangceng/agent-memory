**安装方式**：用系统已有 Python 创建 venv，依赖从**阿里云 PyPI 镜像**安装（实测 559 ms 可达，官方源 2135 ms）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lite.txt `
    -i https://mirrors.aliyun.com/pypi/simple `
    --trusted-host mirrors.aliyun.com --progress-bar off
```

> **说明**：官方 README 推荐 Python 3.9（配合 vllm）。本项目不使用 vllm（Windows 不友好），只用 API 调用 + 官方判分脚本，因此 Python 3.12 无影响。
