# 两周执行清单（2026-10-17 → 2026-10-31）

**目标**：跑通 LongMemEval 评测链路，产出**第一组基线数字**（全量上下文 / 滑动窗口 / 朴素 RAG）。

**验收标准**：有一张三行表格，每行有准确率和 Token/题，且命令可复现。

---

## 架构决策（先定下来，避免走弯路）

### 只用官方仓库的两样东西

| 用途 | 用官方 | 说明 |
|---|---|---|
| 数据集 | ✅ | 官方 cleaned 版本 |
| **判分** | ✅ `src/evaluation/evaluate_qa.py` | 不要自己写判分 |
| 检索基线 | ⬜ 后期可选 | `src/retrieval/run_retrieval.sh` |
| 生成基线 | ❌ **不用** | 官方脚本依赖 `vllm`，Windows 不友好；且你后面要接自己的记忆系统，自己写更可控 |

### 分工

```
你写：hypothesis 生成器（读数据 → 调 LLM → 输出 jsonl）
官方：evaluate_qa.py（读 jsonl + 数据 → 输出准确率）
```

**接口就是**：你的生成器输出 `jsonl`，每行 `{"question_id": "...", "hypothesis": "..."}`。

## Day 2（10/18）：拉官方仓库，打通判分

### 2.1 clone 官方便于取判分脚本

```powershell
mkdir third_party
cd third_party
git clone https://github.com/xiaowu0162/LongMemEval.git
```

### 2.2 读三个文件（只读，不改）

| 文件 | 看什么 |
|---|---|
| `src/evaluation/evaluate_qa.py` | 判分用的 client 怎么初始化、模型名怎么传、输出到哪 |
| `src/evaluation/print_qa_metrics.py` | 分项指标怎么汇总 |
| `README.md` 的 "Testing Your System" | 命令行参数顺序 |

### 2.3 ⚠️ 关键决策点：判分模型

官方 `evaluate_qa.py` 默认调 **OpenAI + gpt-4o** 判分。你有两个选择：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A（推荐）** | 改脚本里的 client 为 OpenAI 兼容端点（DeepSeek base_url） | 便宜，全程国产 | 需自己改 3–5 行；判分质量要抽检 |
| B | 单开一个 OpenAI key 专用于判分 | 与论文默认一致，可比性最好 | 花钱；需要外网 |

**选定后写进 `.env`，并且之后永不更换判分模型**——换判分模型则历史结果全部不可比。

**抽检要求**：无论选哪个，都要**人工看 20 条**判分结果，确认判分模型没有乱判。这一步写进论文的"实验设置"。

### 2.4 冒烟测试判分链路

先手工造一个 3 行的假 jsonl（`hypothesis` 随便写），跑通：

**完成标志**：生成 `.log` 文件，能跑 `print_qa_metrics.py` 打印出分项指标。

## Day 3–4（10/19–10/20）：写第一个生成器（全量上下文）

### 3.1 新建脚本

`experiments/01_baseline_full_context.py`，逻辑：

```
读 data/longmemeval_oracle.json
for 每题（先取前 SUBSET_SIZE=50 题）:
    把 haystack_sessions 按时间顺序拼成文本
    拼 prompt：历史 + 问题 + 问题日期
    调 LLM
    写一行 {"question_id": ..., "hypothesis": ...} 到 results/01_fullctx.jsonl
```

**要点**：
- 用 `oracle` 数据先跑（只含证据会话，token 省，链路最容易通）
- 每题**只调 1 次**模型（这是基线）
- 记录每题 token 消耗（从 API 返回的 usage 里取），存到 `results/01_fullctx_usage.csv`
- **加断点续跑**：每写完一行就 flush，跑挂了能接着跑

### 3.2 冒烟：先 5 题

```powershell
python experiments/01_baseline_full_context.py --subset 5
```

确认：无报错、jsonl 格式正确、usage 有记录。

### 3.3 跑 50 题

```powershell
python experiments/01_baseline_full_context.py --subset 50
```

**完成标志**：`results/01_fullctx.jsonl` 有 50 行。
