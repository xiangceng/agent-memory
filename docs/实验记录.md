### [000] 冒烟测试：oracle 数据 + 全量上下文

- **日期**：2026-10-17
- **目的**：验证评测链路是否跑通，确认单题 token 消耗与耗时
- **配置**：longmemeval_oracle.json / 前 5 题 / deepseek-chat / temperature=0 / max_tokens=512

  ```
  .\.venv\Scripts\python.exe experiments\01_baseline_full_context.py --subset 5
  ```

## 附：指标口径备忘

| 指标 | 定义 | 备注 |
|---|---|---|
| 准确率 | LongMemEval 官方 `evaluate_qa.py` 的自动判分结果 | 判分模型**不可中途更换**，否则历史结果不可比 |
| Token/题 | 输入 token + 输出 token，按题取均值 | 成本对比的核心指标 |
| 调用次数/题 | 该题触发的模型请求次数 | 门控机制的核心指标 |
| 拦截率 | 被门控前两级拦下的内容占比 | 仅适用本方案 |
| 信息保留率 | 压缩前后关键实体保留比例 | 仅适用本方案 |
