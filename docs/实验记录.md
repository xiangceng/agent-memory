### [001] B1 全量上下文基线（oracle，50 题，分层抽样）

- **日期**：2026-10-24
- **目的**：取得第一组可用于对比的基线准确率
- **配置**：`longmemeval_oracle.json` ｜ `--subset 50 --stratified` ｜ `deepseek-chat` ｜ 判分模型 `deepseek-chat`
- **命令**：

  ```powershell
  # 1. 生成
  .\.venv\Scripts\python.exe experiments\01_baseline_full_context.py --subset 50 --stratified --out results\01_fullctx_s50.jsonl
  # 2. 判分
  .\.venv\Scripts\python.exe third_party\LongMemEval\src\evaluation\evaluate_qa.py deepseek-chat results\01_fullctx_s50.jsonl data\longmemeval_oracle.json
  # 3. 汇总
  .\.venv\Scripts\python.exe scripts\report_metrics.py results\01_fullctx_s50.jsonl.eval-results-deepseek-chat data\longmemeval_oracle.json
  ```

- **样本**：50 题，按题型分层（knowledge-update 8 / multi-session 13 / single-session-assistant 6 / single-session-preference 3 / single-session-user 7 / temporal-reasoning 13）

- **结果**：

| 题型 | 准确率 | 题数 |
|---|---|---|
| single-session-assistant | **1.0000** | 6 |
| knowledge-update | **1.0000** | 8 |
| single-session-user | 0.8571 | 7 |
| temporal-reasoning | 0.8462 | 13 |
| multi-session | 0.6923 | 13 |
| single-session-preference | **0.3333** | 3 |
| **Task-averaged** | **0.7882** | |
| **Overall** | **0.8200** | 50 |

- **一句话结论**：在 oracle 设置（仅给证据会话）下，全量上下文的整体准确率为 **82.0%**；最弱的是 **single-session-preference（33%）** 与 **multi-session（69%）**，说明"个性化偏好遵循"与"跨会话聚合"是全量上下文也难以处理的能力。

- **⚠️ 重要说明**：oracle 设置只提供证据会话，属于**检索上限条件**，本结果用于验证评测管线与建立参照，**不作为论文主对比表**。主实验须在 S 设置（≈122k tokens/题，47.7 会话）上进行。

- **异常/踩坑**：
  1. 首次运行 `--subset 12 --stratified` 时分层未生效，原因是脚本**先截断再分层**，已在 2026-10-24 修复为**先分层再截断**。
  2. 修复前产生的混入结果已删除并重跑。

- **对应论文章节**：第六章 6.x「基线实验（oracle 设置）」
- **结果文件**：`results/01_fullctx_s50.jsonl`、`results/01_fullctx_s50_usage.csv`、`results/01_fullctx_s50.jsonl.eval-results-deepseek-chat`

## 附：指标口径备忘

| 指标 | 定义 | 备注 |
|---|---|---|
| 准确率 | LongMemEval 官方 `evaluate_qa.py` 的自动判分结果 | 判分模型**不可中途更换**，否则历史结果不可比 |
| Token/题 | 输入 token + 输出 token，按题取均值 | 成本对比的核心指标 |
| 调用次数/题 | 该题触发的模型请求次数 | 门控机制的核心指标 |
| 拦截率 | 被门控前两级拦下的内容占比 | 仅适用本方案 |
| 信息保留率 | 压缩前后关键实体保留比例 | 仅适用本方案 |

## 附：预算备忘
